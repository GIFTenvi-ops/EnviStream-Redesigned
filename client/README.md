# 🌱 EnviStream — Redesigned

> **A modern, interactive, and responsive digital experience for EnviStream SmarTech.**

EnviStream Redesigned is a complete visual and UX redesign of the EnviStream SmarTech website, focused on creating a more immersive, modern, and responsive experience across desktop, tablet, and mobile devices.

The redesign replaces the previous visual direction with a contemporary dark interface, vibrant gradients, smooth animations, interactive scrolling, and a responsive layout.

---

* 🎨 **Modern UI/UX**

  * Redesigned visual language
  * Dark, premium interface
  * Vibrant gradient accents
  * Improved typography and spacing

* 🖱️ **Interactive Scrolling**

  * Smooth scrolling experience
  * Interactive section navigation
  * Scroll progress indicator
  * Active-section tracking
  * Smooth navigation between sections

* 📱 **Fully Responsive**

  * Desktop optimized

  * Clean component structure

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/GIFTenvi-ops/EnviStream-Redesigned.git
```

### 2. Navigate into the project

```bash
cd EnviStream-Redesigned
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite, usually:

```text
http://localhost:5173
```

---

## 🏗️ Build for Production

Create a production build with:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🎯 Design Direction

The redesigned interface focuses on creating a balance between **technology, sustainability, and visual immersion**.

### Visual Language

* Dark graphite backgrounds
* Violet and fuchsia gradients
* Cyan accent highlights
* High-contrast typography
* Glassmorphism-inspired surfaces
* Soft glow effects
* Large editorial typography
* Minimal but expressive UI elements

The goal is to make the website feel **technological, futuristic, and environmentally conscious** without sacrificing usability.

---

## 🧭 Interactive Navigation

The redesign removes the previous **"Your Path with EnviStream"** section.

Instead, the scrolling experience uses an interactive navigation system that allows visitors to understand their position within the page and quickly move between sections.

The navigation includes:

* Current section indicator
* Scroll progress
* Clickable navigation points
* Smooth section transitions
* Responsive mobile behavior

## ♿ Accessibility

The interface includes accessibility-conscious behavior such as:

* Semantic HTML where applicable
* Keyboard-friendly interactions
* Responsive layouts
* Reduced-motion support
* Readable contrast
* Touch-friendly interactive elements

Users who prefer reduced motion can experience a less animated version of the interface.
